## API 接口

### 核心交易配置 API

#### 加载风控配置
```
GET /api/v1/trading/risk-config
```

#### 保存风控配置
```
POST /api/v1/trading/risk-config
Content-Type: application/json

{
  "maxPositionPercent": 35.0,
  "maxDailyTrades": 9999,
  "stopLossPercent": -1.0,
  "takeProfitPercent": 5.0,
  ...
}
```

## 使用说明

### 核心交易配置
1. 打开前端界面，进入"交易策略配置"卡片
2. 在各个配置区域修改参数
3. 点击"保存所有配置"按钮保存所有修改
4. 点击"恢复默认"按钮将所有参数恢复到与示例项目一致的默认值

### 麻雀战法配置 ✅ (新增)
1. 打开前端界面，进入"麻雀战法配置"卡片
2. 启用麻雀战法开关
3. 在各个配置区域调整参数：
   - **基础参数**: 设置本金、日目标、周目标
   - **时区配置**: 根据不同时段设置仓位范围、持仓时间、日目标占比
   - **止盈配置**: 设置分层止盈和动态止盈策略
   - **止损配置**: 设置软止损、硬止损和时间止损
   - **选股门槛**: 设置趋势评分、共振评分、波动率等
   - **仓位管理**: 设置最大持仓数、单币最大、总仓位上限
   - **日度控制**: 设置盈利目标、亏损限制、连续亏损等
   - **检查频率**: 设置活跃时段和清淡时段的检查间隔
4. 点击"保存配置"按钮保存修改
5. 点击"恢复默认"按钮将所有参数恢复到默认值

## 注意事项

- 所有参数修改会立即生效
- 恢复默认值会将参数恢复到与 crypto-trading-bot-master 示例项目一致的值
- 修改参数前建议先理解各参数的作用和影响
- 每日最大交易次数设置为 9999 表示不限制交易次数
- **麻雀战法配置独立于核心交易配置，需要单独启用**
- 麻雀战法启用后，会根据时区动态调整仓位和交易频率
- 建议根据账户本金合理设置日目标和周目标
