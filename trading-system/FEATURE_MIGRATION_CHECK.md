## 📝 未迁移功能详细说明

### 趋势变盘减仓 (Trend Reversal)

**示例项目逻辑**:
```javascript
// 检查趋势变盘减仓
const reversalCheck = checkTrendReversal(coin, sentiment.score);
if (reversalCheck.shouldReduce && pnlPercent > 0) {
    const reduceAmount = pos.amount * reversalCheck.reducePercent;
    decision = {
        action: 'sell',
        reason: `${reversalCheck.reason}，减仓50%保护利润`,
        amount: reduceAmount
    };
}
```

**配置参数**:
```javascript
const TREND_REVERSAL_CONFIG = {
    enabled: true,
    highTrendThreshold: 8,    // 高趋势阈值
    lowTrendThreshold: 5,     // 低趋势阈值
    sidewaysPeriods: 3,        // 横盘周期数
    reducePercent: 0.5         // 减仓比例50%
};
```

**示例项目功能**:

**关键函数**:
