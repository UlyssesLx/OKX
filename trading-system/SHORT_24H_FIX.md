# 做空策略24h涨跌参数修正说明

## 问题发现

用户指出：做空策略的24h涨跌参数设置有误。

### 错误理解

**原始设计（错误）：**
```python
# 做多
min_24h_change: -5%   # 允许下跌-5%（抄底）
max_24h_change: +8%   # 允许上涨+8%

# 做空（错误❌）
min_24h_change: -5%   # ❌ 错误！不应该允许下跌
max_24h_change: +8%   # ❌ 错误！和做多一样
```

## 正确理解

### 做空的本质

做空 = 认为价格会下跌

所以做空应该在：
- ✅ 价格正在上涨时做空（捕捉顶部）
- ✅ 价格已经涨了很多时做空（超买反转）
- ❌ 价格下跌时做空（已经跌了，可能反弹）

### 修正后的设计

**做多策略：**
```
24h涨跌：-5% ~ +8%
- 允许下跌-5%：抄底机会
- 允许上涨+8%：追涨机会
```

**做空策略：**
```
24h涨跌：+2% ~ +8%
- 至少上涨+2%：说明正在涨（有做空理由）
- 最多上涨+8%：涨太多也不做（避免追高）
```

## 逻辑对比

### 做多策略

```
情景1：BTC价格$100，24h涨跌-3%
→ 满足条件：-5% ≤ -3% ≤ +8%
→ 操作：买入（抄底）

情景2：ETH价格$100，24h涨跌+5%
→ 满足条件：-5% ≤ +5% ≤ +8%
→ 操作：买入（追涨）

情景3：LTC价格$100，24h涨跌+10%
→ 不满足条件：+10% > +8%
→ 操作：不买入（涨太多）
```

### 做空策略（修正后）

```
情景1：BTC价格$100，24h涨跌+3%，RSI=75，趋势=3分
→ 满足条件：+2% ≤ +3% ≤ +8%
→ 操作：做空（正在上涨，超买）

情景2：ETH价格$100，24h涨跌+6%，RSI=80，趋势=2分
→ 满足条件：+2% ≤ +6% ≤ +8%
→ 操作：做空（正在上涨，超买）

情景3：LTC价格$100，24h涨跌-3%，RSI=75，趋势=3分
→ 不满足条件：-3% < +2%
→ 操作：不做空（已经下跌，可能反弹）

情景4：DOGE价格$100，24h涨跌+10%，RSI=75，趋势=3分
→ 不满足条件：+10% > +8%
→ 操作：不做空（涨太多，避免追高）
```

## 为什么修正正确？

### 逻辑合理性

1. **做多策略**：
   - 允许-5%：抄底（价格跌多了，会反弹）
   - 允许+8%：追涨（价格正在涨，会继续）

2. **做空策略**：
   - 要求+2%：正在上涨（有做空理由，捕捉顶部）
   - 最多+8%：涨太多不做（避免追高，风险太大）

### 交易心理学

**做多思维：**
```
"这个币跌了-5%，应该到底了，买入抄底！"
"这个币涨了+5%，还在涨，买入追涨！"
```

**做空思维：**
```
"这个币涨了+3%，RSI也超买了，可能要跌，做空！"
"这个币涨了+6%，RSI极度超买，肯定要跌，做空！"
"这个币跌了-3%，已经跌了，可能反弹，不做空。"
"这个币涨了+10%，涨太多了，FOMO情绪，不做空。"
```

这次修正解决了做空策略24h涨跌参数的逻辑错误，使其更符合做空策略的核心思想：

所以应该在：
- ✅ 价格正在上涨时（+2% ~ +8%）
- ✅ RSI超买时（70-90）
