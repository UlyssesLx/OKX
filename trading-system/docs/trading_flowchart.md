# 自动交易流程图

## 一、系统启动流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                        系统启动 (main.py)                              │
└─────────────────────────────────────────────────────────────────────┘
                                 │
                                 ▼
┌─────────────────────────────────────────────────────────────────────┐
│  1. 加载环境配置 (.env)                                              │
│     - OKX_API_KEY, OKX_SECRET_KEY, OKX_PASSPHRASE                   │
│     - TRADING_MODE (simulation / live)                               │
│     - DATABASE_URL                                                   │
└─────────────────────────────────────────────────────────────────────┘
                                 │
                                 ▼
┌─────────────────────────────────────────────────────────────────────┐
│  2. 初始化各服务模块                                                  │
│     ├── TradingEngine (交易引擎)                                      │
│     ├── SimulationManager (模拟交易管理器)                            │
│     ├── TradeStats (交易统计)                                         │
│     ├── StrategyEvolution (策略进化)                                   │

                                 │
                                 ▼

                                 │
                                 ▼
```

## 二、交易周期主流程 (run_trading_cycle)

```
┌─────────────────────────────────────────────────────────────────────┐
│                    run_trading_cycle() 主循环                         │
└─────────────────────────────────────────────────────────────────────┘
                                 │
                                 ▼
                    ┌───────────────────────────────────┐
                    │  检查紧急停止状态                    │
                    │  emergency_stop.is_stopped()        │
                    └───────────────────────────────────┘
                                 │
                    ┌────────────┴────────────┐
                    │ 是                      │ 否
                    ▼                         ▼
            ┌───────────────┐       ┌───────────────────────────────────┐
            │ 返回停止状态   │       │ 1. 获取时区感知配置                 │
            │ 终止本次循环   │       │    (00:00-04:00 亚洲尾盘)         │
            └───────────────┘       │    (04:00-08:00 欧美交接)         │
                                    │    (08:00-12:00 亚洲早盘) ← 活跃   │
                                    │    (12:00-16:00 亚洲午盘)           │
                                    │    (16:00-20:00 欧洲早盘) ← 活跃   │
                                    │    (20:00-24:00 美国早盘) ← 最活跃  │
                                    └───────────────────────────────────┘
                                                     │
                                                     ▼
                                    ┌───────────────────────────────────┐
                                    │ 2. 获取账户信息 _get_account_info() │
                                    │    - 总资产 (total_equity)          │
                                    │    - 可用USDT (available_usdt)     │
                                    │    - 持仓列表 (positions)          │
                                    └───────────────────────────────────┘
                                                     │
                                                     ▼
                                    ┌───────────────────────────────────┐
                                    │ 3. 获取候选币种 get_all_coins()    │
                                    │    - 按24h成交额排序                │
                                    │    - 取前20名最活跃币种             │
                                    │    - 过滤稳定币 (USDT/USDC等)      │
                                    └───────────────────────────────────┘
                                                     │
                                                     ▼
                                    ┌───────────────────────────────────┐
                                    │ 4. 优先分析已有持仓的币种           │
                                    │    → 直接进入持仓检查流程           │
                                    └───────────────────────────────────┘
                                                     │
                                                     ▼
                    ┌───────────────────────────────────────────────┐
                    │ 5. 检查是否需要寻找新机会 (持仓 < 3个)            │
                    │    - 是: 筛选高潜力币种                          │
                    │    - 否: 跳过找新币种                            │
                    └───────────────────────────────────────────────┘
                                                     │
                                                     ▼
                                    ┌───────────────────────────────────┐
                                    │ 6. 币种趋势分析 analyze_trend()     │
                                    │    - 获取5m K线数据 (50根)          │
                                    │    - 计算MA5/MA10/MA20             │
                                    │    - 计算MACD/RSI/布林带            │
                                    │    - 计算成交量均线                  │
                                    │    - 输出: trend_score (1-10)       │
                                    └───────────────────────────────────┘
                                                     │
                                                     ▼
                                    ┌───────────────────────────────────┐
                                    │ 7. 多维度共振分析 calculate_resonance()│
                                    │    - 市场环境检查 (market_env)       │
                                    │    - 资金流向检查 (capital_flow)     │
                                    │    - 技术指标验证 (tech_indicators)  │
                                    │    - 输出: resonance_score          │
                                    └───────────────────────────────────┘
                                                     │
                                                     ▼
                                    ┌───────────────────────────────────┐
                                    │ 8. 生成交易信号 generate_signals()   │
                                    │    - 做多信号 (buy)                │
                                    │    - 做空信号 (sell_short)          │
                                    │    - 持仓检查信号 (检查止盈止损)    │
                                    └───────────────────────────────────┘
                                                     │
                                                     ▼
                                    ┌───────────────────────────────────┐
                                    │ 9. 执行交易信号 execute_signal()     │
                                    │    - 模拟模式: 记录到SimulationMgr  │
                                    │    - 实盘模式: 调用OKX API下单       │
                                    └───────────────────────────────────┘
                                                     │
                                                     ▼
                                    ┌───────────────────────────────────┐
                                    │ 10. 策略自进化 check_strategy_evolution()│
                                    │     - 分析今日交易表现               │
                                    │     - 计算胜率/盈亏比                │
                                    │     - 自动调整参数                   │
                                    └───────────────────────────────────┘
                                                     │
                                                     ▼
                                    ┌───────────────────────────────────┐
                                    │ 11. 记录状态并广播 WebSocket         │
                                    │     - coordinator.broadcast()       │
                                    └───────────────────────────────────┘
```

```
                                    │    - 趋势10分: 15分钟             │
                                    │    - 趋势8-9分: 20分钟           │

                                    └───────────────────────────────────┘
                                                     │
                                                     ▼
                                    ┌───────────────────────────────────┐
                                    │ 检查3: 买入条件验证                 │

                                    │    - RSI: 40-60                  │
                                    │    - 成交量比: >= 0.3x            │
                                    │    - 24h涨跌: -2% ~ +5%          │
                                    │    - → 通过则使用 $40/笔          │
                                    │                                  │
                                    │ ② 严格抄底 (Strict Dip)          │

                                                     │
                                                     ▼

                                    │ 检查4: 资金验证                    │

                                    │ - 仓位占比 < 最大持仓限制          │

                                                     │
```

```
                    │    - 24h涨跌: -8% ~ +5%           │
                    │    - 成交量比: >= 0.3x             │
```

## 五、止盈止损检查流程 (check_positions / simulation_manager)

```
┌─────────────────────────────────────────────────────────────────────┐
│                    持仓止盈止损检查 (check_positions)                  │
└─────────────────────────────────────────────────────────────────────┘
                                 │
                                 ▼
                    ┌───────────────────────────────────┐
                    │ 遍历所有持仓币种                    │
                    └───────────────────────────────────┘
                                 │
                                 ▼
                    ┌───────────────────────────────────┐
                    │ 计算当前盈亏                        │
                    │ pnl_percent =                     │
                    │ (当前价 - 入场价) / 入场价 * 杠杆   │
                    └───────────────────────────────────┘
                                 │
                                 ▼
            ┌───────────────────────────────────────────────────────┐
            │                    【做多持仓检查】                      │
            │  check_sell_signals()                                  │
            │                                                        │
            │  ┌─────────────────────────────────────────────────┐  │
            │  │ 动态模式 (dynamic_bands_enabled=True)            │  │
            │  │                                                 │  │
            │  │ 1. 计算动态止盈 (dynamic_take_profit)           │  │
            │  │    - 趋势9-10分: 基础15% × 波动系数 × 市值系数 │  │
            │  │    - 趋势7-8分:  基础10% × 波动系数 × 市值系数 │  │
            │  │    - 趋势5-6分:  基础8%  × 波动系数 × 市值系数 │  │
            │  │    - 其他:      基础6%  × 波动系数 × 市值系数 │  │
            │  │                                                 │  │
            │  │ 2. 计算动态止损 (smart_stop_loss)              │  │
            │  │    - 趋势>=8分: 基础-3%                        │  │
            │  │    - 趋势6-7分: 基础-2%                        │  │
            │  │    - 其他:      基础-1.5%                      │  │
            │  │                                                 │  │
            │  │ 3. 波动率因子 (volatility_factor)              │  │
            │  │    = min(2.0, max(0.5, volatility / 3))      │  │
            │  │                                                 │  │
            │  │ 4. 市值因子 (market_cap_factor)                │  │
            │  │    - 成交额>10亿: 1.2                          │  │
            │  │    - 成交额>1亿:  1.0                          │  │
            │  │    - 其他:       0.6                          │  │
            │  │                                                 │  │
            │  │ 5. 趋势因子 (trend_factor)                    │  │
            │  │    - 趋势>=8分: 1.2                            │  │
            │  │    - 趋势>=6分: 1.0                            │  │
            │  │    - 其他:      0.8                            │  │
            │  │                                                 │  │
            │  │ 6. 时间衰减止损 (time_decay_enabled)           │  │
            │  │    - 每小时收紧 X% (默认0.1%)                  │  │
            │  │    - 最大收紧到 -8%                            │  │
            │  │                                                 │  │
            │  │ 7. 范围限制                                    │  │
            │  │    - 止损: -5% ~ -1%                          │  │
            │  │    - 止盈: 2% ~ 15%                           │  │
            │  └─────────────────────────────────────────────────┘  │
            │                                                        │
            │  ┌─────────────────────────────────────────────────┐  │
            │  │ 【检查顺序】                                    │  │
            │  │                                                 │  │
            │  │ 1. 时间保护检查                                │  │
            │  │    - 新建仓<60分钟: 暂不止损 (除非极端行情)    │  │
            │  │                                                 │  │
            │  │ 2. 止损拦截 → 金字塔加仓                       │  │
            │  │    - 触发止损但趋势>=8分                       │  │
            │  │    - 仓位<15% 且 可用资金>=$25                 │  │
            │  │    - pyramid_layers < 3                       │  │
            │  │    → 建议金字塔加仓 (返回suggest_pyramid)     │  │
            │  │                                                 │  │
            │  │ 3. 止损执行                                    │  │
            │  │    - pnl <= stop_loss_percent                 │  │
            │  │    → 全部卖出 (should_sell: True, 100%)       │  │
            │  │                                                 │  │
            │  │ 4. 止盈执行                                    │  │
            │  │    - pnl >= take_profit_percent               │  │
            │  │    → 全部卖出 (should_sell: True, 100%)       │  │
            │  │                                                 │  │
            │  │ 5. 部分止盈 (50%)                             │  │
            │  │    - pnl >= take_profit * 50%                 │  │
            │  │    - 未执行过部分止盈                          │  │
            │  │    → 部分卖出 (should_sell: True, 50%)        │  │
            │  │                                                 │  │
            │  │ 6. 小盈减仓 (50%)                             │  │
            │  │    - pnl >= take_profit * 50%                 │  │
            │  │    - 仓位 > 15%                               │  │
            │  │    → 部分卖出 (should_sell: True, 50%)        │  │
            │  │                                                 │  │
            │  │ 7. 超仓减仓                                   │  │
            │  │    - 仓位 > 30%                               │  │
            │  │    - 不在豁免期内                              │  │
            │  │    → 减仓至20%                                 │  │
            │  │                                                 │  │
            │  │ 8. 趋势变盘减仓 (50%)                         │  │
            │  │    - 趋势从>=8分 降至 <=5分                   │  │
            │  │    - 持续3个周期以上                           │  │
            │  │    → 部分卖出 (should_sell: True, 50%)       │  │
            │  │                                                 │  │
            │  │ 9. 移动止损 (Trailing Stop)                   │  │
            │  │    - 盈利 >= 3%时激活                         │  │
            │  │    - 最高价 * 0.98 追踪                       │  │
            │  │    - 当前价 <= 追踪价 → 全部卖出              │  │
            │  │                                                 │  │
            │  │ 10. 舆情极差预警                              │  │
            │  │     - 趋势评分 < 3分                          │  │
            │  │     - → 收紧止盈单或市价卖出                  │  │
            │  └─────────────────────────────────────────────────┘  │
            └───────────────────────────────────────────────────────┘
                                 │
                                 ▼
            ┌───────────────────────────────────────────────────────┐
            │                    【做空持仓检查】                     │
            │  check_short_cover_signals()                          │
            │                                                        │
            │  ┌─────────────────────────────────────────────────┐  │
            │  │ 做空盈亏计算                                    │  │
            │  │ pnl_percent = (入场价-当前价)/入场价 * 杠杆 * 100│  │
            │  │ (价格上涨则亏损，下跌则盈利)                     │  │
            │  │                                                 │  │
            │  │ 动态模式:                                       │  │
            │  │ - 止损(止损=价格上涨): 1.5% ~ 8%               │  │
            │  │ - 止盈(止盈=价格下跌): 2% ~ 15%               │  │
            │  │                                                 │  │
            │  │ 【检查顺序】                                    │  │
            │  │ 1. 做空止损 (价格上涨触发)                      │  │
            │  │    - pnl <= -stop_loss → 全部平仓             │  │
            │  │                                                 │  │
            │  │ 2. 做空止盈 (价格下跌触发)                     │  │
            │  │    - pnl >= take_profit → 全部平仓            │  │
            │  │                                                 │  │
            │  │ 3. 做空部分止盈 (50%)                         │  │
            │  │    - pnl >= take_profit * 50%                 │  │
            │  │    → 部分平仓 (should_cover: True, 50%)       │  │
            │  │                                                 │  │
            │  │ 4. 做空时间保护                                │  │
            │  │    - 持仓<60分钟: 暂不平仓                     │  │
            │  │                                                 │  │
            │  │ 5. 做空豁免期检查                              │  │
            │  │    - 亏损>1%: 豁免60分钟                      │  │
            │  │    - 亏损0-1%: 豁免45分钟                     │  │
            │  │    - 盈利: 豁免30分钟                         │  │
            │  │                                                 │  │
            │  │ 6. 做空超仓检查                               │  │
            │  │    - 仓位>30%: 减仓至20%                     │  │
            │  └─────────────────────────────────────────────────┘  │
            └───────────────────────────────────────────────────────┘
```

## 六、金字塔加仓流程 (pyramid)

```
┌─────────────────────────────────────────────────────────────────────┐
│                      金字塔加仓 (Pyramid Buy)                        │
└─────────────────────────────────────────────────────────────────────┘
                                 │
                                 ▼
                    ┌───────────────────────────────────┐
                    │ 触发条件检查                        │
                    │ 1. 亏损 >= PYRAMID_DROP_THRESHOLD │
                    │    (默认: -5%)                    │
                    │ 2. 趋势评分 >= 6分                 │
                    │ 3. 当前仓位 < 15%                  │
                    │ 4. pyramid_layers < 3             │
                    │ 5. 可用资金 >= $25                │
                    └───────────────────────────────────┘
                                 │
                                 ▼
                    ┌───────────────────────────────────┐
                    │ 计算加仓金额                        │
                    │                                  │
                    │ 第一层: $25 × 1.0 = $25         │
                    │ 第二层: $25 × 0.6 = $15         │
                    │ 第三层: $25 × 0.35 = $8.75      │
                    │                                  │
                    │ (每层递减，防止仓位过重)           │
                    └───────────────────────────────────┘
                                 │
                                 ▼
                    ┌───────────────────────────────────┐
                    │ 计算加仓价格                        │
                    │                                  │
                    │ 第一层: 入场价 × (1 + 10%)        │
                    │        = 入场价 × 0.90           │
                    │ 第二层: 入场价 × (1 + 20%)       │
                    │        = 入场价 × 0.80           │
                    │ 第三层: 入场价 × (1 + 30%)       │
                    │        = 入场价 × 0.70           │
                    │                                  │
                    │ (每跌10%加一层)                   │
                    └───────────────────────────────────┘
                                 │
                                 ▼
                    ┌───────────────────────────────────┐
                    │ 执行加仓                           │
                    │ 1. 记录 pyramid_layer_prices      │
                    │ 2. 更新 pyramid_layers 计数       │
                    │ 3. 重新计算持仓均价                │
                    │ 4. 更新止损线 (基于新均价)         │
                    └───────────────────────────────────┘
```
