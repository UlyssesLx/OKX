# 做空策略24h涨跌参数最终修正说明

## 最终正确理解

### 用户指出

"不对应该是允许最大上涨5%，允许跌幅-8%"

### 修正后的逻辑

**做多策略：**
```
24h涨跌：-5% ~ +8%
- 允许下跌-5%：抄底机会
- 允许上涨+8%：追涨机会
```

**做空策略：**
```
24h涨跌：-8% ~ +5%
- 允许下跌-8%：更大的下跌容忍度（允许已经跌了的币做空）
- 限制上涨+5%：限制追高（涨太多不做空）
```

## 逻辑对比

### 参数对比表

| 参数 | 做多 | 做空（最终✅） |
|------|------|----------------|
| 趋势评分 | 6-10分 | 0-4分 |
| RSI | 30-70 | 70-90 |
| 成交量 | ≥ 0.8x | ≥ 0.8x |
| **24h涨跌下限** | **-5%** | **-8%** |
| **24h涨跌上限** | **+8%** | **+5%** |
| 波动率 | 0.3%-5% | 0.3%-5% |

### 做空策略逻辑

**核心思想：做空可以容忍更大的下跌，但限制上涨幅度**

```
情景1：BTC价格$100，24h涨跌+3%，RSI=75，趋势=3分
→ 满足条件：-8% ≤ +3% ≤ +5%
→ 操作：做空（正在上涨，超买，但涨得不多）

情景2：ETH价格$100，24h涨跌-5%，RSI=75，趋势=3分
→ 满足条件：-8% ≤ -5% ≤ +5%
→ 操作：做空（已经下跌，超买，可能继续跌）

情景3：LTC价格$100，24h涨跌-10%，RSI=75，趋势=3分
→ 不满足条件：-10% < -8%
→ 操作：不做空（跌太多了）

情景4：DOGE价格$100，24h涨跌+8%，RSI=75，趋势=3分
→ 不满足条件：+8% > +5%
→ 操作：不做空（涨太多，追高风险）
```

### 与做多策略的区别

**做多：**
- 允许更大的上涨（+8%）：可以追涨
- 限制下跌（-5%）：只抄有限跌幅的底

**做空：**
- 限制上涨（+5%）：不追高
- 允许更大的下跌（-8%）：容忍已经跌了的币

## 为什么这个逻辑正确？

### 交易心理学

**做多思维（追涨+抄底）：**
```
"这个币跌了-5%，应该到底了，买入抄底！"
"这个币涨了+5%，还在涨，买入追涨！"
"这个币涨了+10%，涨太多风险大，不买。"
"这个币跌了-10%，可能还要跌，不买。"
```

**做空思维（不追高+容忍下跌）：**
```
"这个币涨了+3%，RSI超买，可能要跌，做空！"
"这个币跌了-5%，RSI超买，可能继续跌，做空！"
"这个币涨了+8%，涨太多追高风险，不做空。"
"这个币跌了-10%，跌太多可能反弹，不做空。"
```

### 对称性分析

做多和做空策略形成镜像对称：

| 策略 | 下跌容忍度 | 上涨容忍度 |
|------|-----------|-----------|
| 做多 | 保守（-5%） | 积极（+8%） |
| 做空 | 积极（-8%） | 保守（+5%） |

**做多**：
- 下跌保守：只抄有限跌幅的底（-5%）
- 上涨积极：可以追涨（+8%）

**做空**：
- 下跌积极：容忍已经跌的币（-8%）
- 上涨保守：不追高（+5%）
